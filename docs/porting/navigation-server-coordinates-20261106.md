## Java 边界

`ServerNavMeshQuery.Position` 明确表示服务器 Z-up 米制坐标，不能与导航模型的 `NavMesh.Vec3` 隐式互换。前者构造时拒绝非有限值及绝对值超过 1e9 的分量。`toNavigation` 做 `(x,y,z) → (y,z,x)`，`toServer` 做反变换；业务入口与返回值都使用 `Position`。

| 入口 | 已实现行为 |
|---|---|
| `place(position)` | 使用导航半范围 `(2,4,2)` 搜索地表，返回 `FOUND / NOT_FOUND / LIMIT_REACHED`。垂直差严格小于 4 米；水平范围继承最近点查询的候选 AABB 语义。失败无位置，不用原点或出生点占位。 |
| `move(from,to)` | 吸附起点、验证整段射线、按地表高度裁决终点；撞墙时按原三维输入线段长度退 0.05 米，并重新沿同一起点射线求回缩位置。回缩不越过起点。 |
| `findPath(from,to)` | 吸附起终点后调用已有地表 A*；保留走廊、地表点引用及台阶两侧高度，输出全部换为服务器坐标。只有 `COMPLETE` 有完整点列。 |

查询对象仅持不可变几何索引及过滤配置，各调用的工作区仍私有。没有 Spring、protobuf、场景实体、线程调度、文件 I/O 或全局状态依赖。

## 移动状态与明确差异

- `CLEAR`：整段已证明可达，终点高度来自实际到达的地表。
- `HIT_WALL`：返回回缩后的安全位置；数值边界导致二次射线无法证明时退回吸附起点。
- `END_HEIGHT_OUT_OF_RANGE`：射线可达，但上报终点距实际地表高度大于等于 4 米；按终点前 5 cm 规则退回，不能将其当正常移动。
- `INVALID_START`：起点不在搜索范围内；没有位置，调用方保留原位置并选择明确恢复流程。
- `LIMIT_REACHED`：起点搜索耗尽时没有位置；起点已证明但后续射线耗尽时只返回吸附起点，绝不应用部分射线进度。该状态不是确定撞墙或确定不可达。

默认单次底层查询工作量为 1,048,576，射线经过面上限 256，路径预算沿用已有默认值。组合移动最多做一次最近点及两次射线，组合寻路最多做两次最近点和一次路径查询；预算按底层阶段计，不宣称共享一份总工作量。构造器允许显式收紧既有查询/路径预算，供调用方与测试使用。

两处对照差异有意保留：

1. C++ 会在终点与回缩点再次全局 `findNearestPoly`。Java 终点使用射线实际到达的引用，回缩使用从原起点的二次射线，避免多层地形跳到未连通的楼层或墙后。终点高度范围仍为严格 4 米。该行为不是 Detour 逐位对齐。
2. 路径继承 Java 库的完整/失败合同，不输出 C++ 可接受的部分路径。若业务需要最近可达点，须增加独立状态及完整性合同。

本类不决定未配置导航时的放行策略，也不改变现有三图 mask。场景接入仍需负责绑定/产物来源校验、进场恢复、速度清零、当帧 133 推送、137 纠偏、MoveGuard 最终锚点且不退款；不得因新增本类就宣称这些生产路径已接通。

## 回归源码与验证边界

17 个测试方法覆盖坐标换轴、数值拒绝、搜索范围、合法移动高度、四向 5 cm 回缩、近墙不后退、斜坡投影、起点缺失、原地/终点超高、多层不换层、flags、起点/射线预算、路径端点/不可变结果/失败、并发独立工作区。

首次统一 Maven/JUnit 运行中，本适配器 17 个方法有 1 个失败：常高 3 米被绝对高度加权计算为 `3.0000000000000004`。`NavMeshGeometry` 改用以第一个顶点高度为基准的差值插值，保留原精确断言，常高面保持原高度；斜面仍按同一重心坐标计算。

同次固定资产用例在 `main` tile 数据偏移 24280 处被既有 reader 的严格流形规则拒绝。仓外 `D:/luyuan/tools/review-port-next/fixed-nav-92952c84` 的 6 份资产均存在，长度与测试声明的 SHA-256 一致，无需重新导出或跳过。原产物的 main、donghai、dungeon、mirror 各含一个同高、无额外 detail 顶点的冗余三角形面；其中存在完整凸面剖分，额外三角形只重复覆盖同一高度。

`MsetReader` 现在仅对上述几何条件另作验证：每个三角形仍须方向正确、非退化、不重复、位于凸面内且边界标志合法；区间动态规划还须证明现有三角形包含完整无缺口的凸面剖分。不同高度、额外 detail 顶点或不具完整剖分时不走该分支，其余曲面仍保持原有边配对与面积校验。新增 4 个测试验证可接受冗余、缺角拒绝、冲突高度拒绝和完全重复三角拒绝；不依赖地图名字或哈希特判。

当前只完成修复后的静态差异检查；后续统一测试结果由根任务记录。尚未完成性能负载或客户端验收。仍缺 scene 接入、余下 6 个配置的导航绑定、离线烘焙工具、off-mesh 和完整 C++ 金样。
